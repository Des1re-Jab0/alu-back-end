# alu-back-end — API

This project uses the JSONPlaceholder REST API to retrieve an employee's TODO list progress.
Scripts fetch task data by employee ID and display or export it in CSV and JSON formats.
Built with Python 3, using the `requests`/`urllib` and `csv`/`json` standard modules.
Each script runs from the command line and is guarded by `if __name__ == "__main__":`.
